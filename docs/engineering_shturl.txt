    - docs：项目文档、部署说明、演示截图、工程日志
    - examples：测试提示词样例
2. 编写代码
    - utils.py：封装load_config函数，读取yaml配置文件
    - main.py：命令行对话交互循环，加载配置；修复相对路径读取配置文件的bug
3. 文档编写
    - README.md：项目简介与功能
    - setup.md：项目部署说明
    - demo_screenshot.md：程序运行演示示例

4. 版本管理：每完成一个文件，执行git add / commit / push，同步到GitHub远程仓库

### 遇到的问题与解决
问题：运行main.py时抛出FileNotFoundError，找不到config.yaml配置文件。
原因：直接使用相对路径`../config/config.yaml`，在不同工作目录运行容易出错。
解决方案：使用os读取当前脚本绝对路径，再拼接配置文件路径，保证程序位置无关。
